## What this playtest is actually testing

`game-concept.md` makes a falsifiable pair of claims that pull against each other:

> *"In a **close, undecided** game, losing tempo is recoverable through smart stabilization — the
> swing can still flip while the outcome is in doubt. OVERCLOCK deliberately has no
> rubber-band/comeback mechanic: once a game is **actually decided**, it is not designed to
> reverse."*

Two requirements, and only one of them is easy:

| | Requirement | Difficulty |
|---|---|---|
| **1** | No decided game reverses | Easy to pass |
| **2** | There *is* a window where the outcome is in doubt | Easy to fail **silently** |

★ **A game decided on turn 2 satisfies requirement 1 perfectly and has no swing whatsoever.**
Measuring only "did anything reverse" scores that as a pass. So this analysis measures *when* the
decision happens, not just whether it holds.

---

## 1. ✅ Requirement 1 — no decided game reverses

**Passes cleanly.** Across the 18 handicapped games — every one of which starts with a real material
advantage — there is **not one lead change**. An advantage, once held, is never surrendered.

```
handicap +1 : 0 lead changes across 6 games
handicap +2 : 0 lead changes across 6 games
handicap +3 : 0 lead changes across 6 games
```

The design intent here is explicit and this is exactly it: no rubber-banding, no hidden catch-up.

## 2. ✅ Requirement 2 — the swing is alive in close games

**Also passes, and by a wider margin than expected.** In the four symmetric mirror matches — the
only genuinely close games in the set:

| Measure | Mirror games |
|---|---:|
| Mean window of doubt *(share of the game still undecided)* | **48 %** |
| Mean lead changes per game | **6.75** |
| Best game (variant 3) | **100 % doubt, 12 lead changes** |

One of the four is in doubt until the final turn and changes hands twelve times. When this game is
close, it is genuinely close, and the lead moves. That is the thing the pillar promises.

---

## 3. ★★ THE CONCERN — the cliff between "alive" and "over" is one unit wide

This is the finding worth acting on, and it is not either requirement failing.

| Handicap | Window of doubt | Lead changes |
|---|---:|---:|
| **+0** (mirror) | **48 %** | **6.75** |
| **+1** (one Trooper) | **3 %** | **0.00** |
| +2 | 0 % | 0.00 |
| +3 | 0 % | 0.00 |

**A single extra Trooper takes the game from "changes hands seven times" to "never changes hands at
all."** There is no gradient between them. The state space is a mirror match or a foregone
conclusion, with nothing in between.

That is a real design property rather than a bug, and it follows from choices already made
deliberately — deterministic combat, no randomness, no comeback mechanic. But it has a consequence
worth naming: **the game's entire drama budget lives in an exactly-even position.** Any deviation
spends it all at once.

> ⚠️ This is where I would look before adding content. Wave 2's classes, damage types and abilities
> add *decisions*, and this measurement says the game does not currently lack decisions — it lacks a
> **recoverable middle**. More unit variety will not create one; something that lets a behind player
> convert skill into position might.
>
> ★ Nothing here recommends a rubber-band mechanic — the concept explicitly rejects it, twice, and
> that rejection is upheld by requirement 1 passing. The question is narrower: is there a *skill*
> route back from one unit down, and right now the measurement says no.

---

## 4. ★ UNEXPECTED — the player who moves first loses every mirror

All four symmetric games, both seats, and the result is unanimous:

| Variant | Moved first | Won | Final HQ (P0 / P1) |
|---|---|---|---|
| 0 | P0 | **P1** | 22 / 38 |
| 1 | P1 | **P0** | 37 / 11 |
| 2 | P0 | **P1** | 11 / 36 |
| 3 | P1 | **P0** | 26 / 22 |

**4/4 first-player losses**, and not by tiebreak technicality — these are real HQ-damage differences
(the widest is 11 vs 36).

The plausible mechanism is that on a symmetric board the first player must commit into the open,
and the second player answers with full information about that commitment. Whatever the cause, a
**first-move disadvantage** is worth knowing about before any competitive tuning, and it is the
opposite of the usual expectation.

⚠️ Four games with one deterministic AI is a signal, not a proof. It is unanimous and it is worth a
follow-up, but it is not yet a balance finding.

## 5. Closeout drag

The GDD flags this as a named risk. Measured, it splits by game type:

| Game type | Decided at | Game length | Drag |
|---|---|---|---|
| Mirror (+0) | ~turn 29 of 60 | 60 (round cap) | 31.5 turns |
| Handicapped | turn 0–2 | 21–32 turns | the whole game |

For handicapped games, "drag" is definitionally the entire match — the advantage exists at setup, so
every turn after that is conversion. **The honest reading is that converting a won position takes
21–32 turns, which is the same length as a close game.** Winning decisively and winning narrowly cost
the same amount of the player's time.

Mirror games always reach the round cap, which is correct behaviour: a dead-even deterministic match
*should* be decided by the tiebreak metric rather than by one side blundering.

## 6. ⛔ Still owed — the human half

`PIVOT-NOTE.md` names three analyses no simulation can perform. They remain outstanding:

| | Question | Why a script cannot answer it |
|---|---|---|
| **A** | Does the swing *feel* alive? | 6.75 lead changes is a number. Whether a player *notices* them, and feels the game is theirs to lose, is not |
| **C** | Does tempo read at a glance? | Depends on the HUD communicating AP and Credit state, which S6-07 only just shipped |
| **D** | Does spending Credits *feel* like a tempo cost? | ★ **This is the economy pivot's core hypothesis.** The whole two-budget design rests on it, and no simulation can touch it |

**Analysis D is the important one.** Sprint 4's pivot split one budget into two on the premise that
paying a tempo price for economic investment would feel deliberate rather than fiddly. Every
measurement since has confirmed the mechanism *works*; none has tested whether it *feels* like
anything.

### Harness change made for this playtest

The mirror cell was previously **n = 1 disguised as n = 3**: `variant` reached the board only through
the bonus-unit placement, which sits inside the handicap loop, so at +0 all three "variants" were
byte-identical runs of one deterministic match. Since the mirror is the *only* cell that can test
swing at all, S5-04 had no data until this was fixed.

It now runs four symmetric openings — each seeding **both** players identically at mirrored tiles,
with the starting player alternating. Fair openings, different games. **Handicap cells are untouched
on purpose**, so S6-06 gate numbers stay comparable batch to batch (verified: 18/18 conversion,
identical game lengths).
